## 一、整体设计思路

我建议采用：

> **“2D数据驾驶舱 + 3D青岛地图 + 动态数据图层 + AI智能洞察”**

整体保持深色科技风，但中间地图从现在的平面行政区地图，改成一个**倾斜45°左右俯视的3D青岛地图**。

页面结构：

```text
┌──────────────────────────────────────────────────────────┐
│              医疗服务辐射智能决策平台                    │
│  2026年   全院   门诊+住院    科室▼       AI智能巡检     │
├──────────────┬─────────────────────────┬─────────────────┤
│              │                         │ AI智能洞察      │
│ 人口统计     │                         │                 │
│              │      3D 青岛地图        │ 🔴异常增长      │
│ 就诊统计     │                         │ 🟠覆盖不足      │
│              │   ███ 市南              │ 🟢专科优势      │
│ HRI          │    ██ 市北              │                 │
│              │     █ 城阳              │ [查看原因]      │
│ 趋势         │                         │                 │
├──────────────┴─────────────────────────┴─────────────────┤
│ 人口分布 │ 患者分布 │ 每万人就诊 │ HRI │ AI机会地图     │
└──────────────────────────────────────────────────────────┘
```

**中间60%左右的视觉空间全部交给地图。**

这会比现在传统“九宫格BI大屏”高级很多。

---

# 二、地图不要简单做成“厚一点”

这是设计上的关键。

很多所谓3D地图只是：

> GeoJSON + `extrude`

把每个区向上拉几十像素。

效果其实很廉价。

你应该把3D地图设计成：

### 第一层：城市地理底座

最下面是：

> 青岛市3D地理底图。

深蓝/黑色。

能看到：

* 海岸线；
* 胶州湾；
* 青岛陆地区域；
* 主要道路；
* 城市建筑轮廓。

地图整体倾斜：

> 40°～50°。

让用户明显感觉是在“俯视青岛”。

---

# 三、第二层：街道3D行政区

在地理底座上覆盖你的：

> 青岛街道GeoJSON。

每个街道做成一个稍微有厚度的3D Polygon。

比如：

```text
        ┌──────────┐
        │ 市南区   │
        │ HRI 1.42 │
        └──────────┘
        ███████████
        ███████████
        ███████████
```

但是这里我建议：

### 高度不要代表数据。

所有行政区域保持基本相同高度。

因为如果：

> 高度 = 患者人数
> 颜色 = HRI

地图会很难理解。

所以：

> **行政区高度只负责制造3D质感。**

数据主要用颜色、光柱、粒子等表达。

---

# 四、第三层才是真正的数据层

设计5种地图模式。

底部按钮：

```text
人口分布 | 患者分布 | 每万人就诊 | HRI | AI机会
```

点击以后，3D地图不用重新加载，只切换数据表现。

---

## 模式一：人口分布

不要简单改变地图颜色。

建议：

> **人口密度 = 3D光柱**

例如：

```text
        │
      │ │
    │ │ │
  │ │ │ │
███████████
```

人口越密集：

> 光柱越高、越密。

这样青岛核心城区会明显“隆起”。

视觉效果很好。

---

# 五、模式二：患者分布

这个可以做成：

### 发光粒子热力图

患者越多的地方：

> 蓝 → 青 → 黄 → 橙 → 红。

例如核心城区：

```text
        🔴
      🟠🔴🟠
    🟡🟠🔴🟠
  🔵🟡🟠🟠🔵
```

不是实际画Emoji，而是GPU粒子/Heatmap。

这样：

> **患者来源热点**

一眼就能看到。

---

# 六、模式三：每万人就诊

这里建议用：

### 3D街道分级设色

例如：

```text
深蓝    很低
蓝      偏低
青      一般
黄      较高
橙      高
红      很高
```

鼠标放到某街道：

```text
┌─────────────────────┐
│ 城阳街道            │
│                     │
│ 人口       42.6万   │
│ 患者       1.82万   │
│ 每万人     427人    │
│                     │
│ 同比       ↑18.2%   │
└─────────────────────┘
```

弹窗可以做半透明玻璃效果。

---

# 七、HRI地图应该成为“主地图”

这个最值得炫。

颜色：

```text
HRI < 0.5
深蓝

0.5–1.0
青色

1.0–1.5
黄色

>1.5
橙红
```

但是增加一个非常关键的视觉效果：

> **HRI越高，区域边界光晕越明显。**

例如核心区域：

```text
         ╔══════════╗
      ╔══╝          ╚══╗
     ║     市南区       ║
     ║    HRI 1.82      ║
      ╚══╗          ╔══╝
         ╚══════════╝
```

有一圈发光边界。

这样会非常有“医疗辐射能量场”的感觉。

---

# 八、AI机会地图可以做得最炫

这个模式不是展示现状。

而是展示：

> **AI发现的未来重点区域。**

普通区域保持深蓝。

AI发现：

> 高潜力区域

出现橙色呼吸光圈：

```text
             ◎
           ◎ ◎
         ◎  ★  ◎
           ◎ ◎
             ◎
```

并显示：

> **AI Opportunity 87**

点击以后：

```text
┌─────────────────────────┐
│ AI发现：高潜力服务区域   │
│                         │
│ 人口增长       +16.8%    │
│ 患者增长        +4.2%    │
│ HRI              0.43    │
│                         │
│ 潜力评分          87     │
│                         │
│ [查看AI分析]             │
└─────────────────────────┘
```

这会把你前面准备增加的**AI智能巡检**和3D地图结合起来。

---

# 九、点击AI事件时，地图要“飞过去”

这个效果非常重要。

例如右侧出现：

> 🔴 城阳某街道患者异常增长

用户点击。

不要地图瞬间跳过去。

而是：

```text
青岛全景
   ↓
Camera FlyTo
   ↓
城阳区
   ↓
继续Zoom
   ↓
目标街道
```

大约：

> 1～1.5秒。

镜头飞过去。

目标街道开始：

> **呼吸发光。**

右侧打开：

> AI原因归因。

这个交互在比赛现场非常有视觉冲击力。

---

# 十、2020—2026时间变化也要利用3D

底部放：

```text
2020 ━━●━━ 2021 ━━━ 2022 ━━━ 2023 ━━━ 2024 ━━━ 2025 ━━━ 2026
```

点击播放：

> ▶

地图自动：

```text
2020
 ↓
2021
 ↓
2022
 ↓
……
 ↓
2026
```

每年地图颜色、热点、HRI变化。

于是你可以展示：

# 医疗辐射时空演化

例如某区域：

```text
2020  🔵
2021  🔵
2022  🟢
2023  🟢
2024  🟡
2025  🟠
2026  🔴
```

视觉上直接看到医院医疗辐射逐年向某个方向扩展。

这个效果非常适合比赛。

# 十一、还可以加一个“医院中心点”

地图上把医院位置做成：

> **医疗能量核心**

不是普通红点。

可以是：

```text
        ╱│╲
      ╱  │  ╲
    ╱    ✚    ╲
   ─────────────
      医院名称
```

蓝色/青色呼吸光。

然后从医院到主要患者来源区域增加：

> **动态飞线。**

例如：

```text
医院 ● ───────→ 城阳
     ╲
      ╲────────→ 李沧
       ╲
        ╲───────→ 即墨
```

线上有流动粒子。

患者数量越多：

> 飞线越亮。

这就是：

### 医疗服务辐射流向

视觉效果非常强，而且业务意义也合理。

---

# 十二、不要把所有街道名字一直显示

否则3D地图会变得非常乱。

默认只显示：

> 10个区市名称。

Zoom进去以后：

> 才显示街道名称。

例如：

```text
青岛全景
→ 显示区市

Zoom 10
→ 显示重点街道

Zoom 12
→ 显示所有街道
```

这样地图干净很多。

---

# 十三、技术上我建议换一个地图引擎

如果你现在只是：

> HTML + ECharts Geo

那么继续做3D会比较受限制。

我更推荐：

### MapLibre GL JS

它是开源地图引擎，很适合你的HTML项目。

可以实现：

* 3D地图；
* Fill Extrusion；
* 建筑物；
* GeoJSON；
* 飞行动画；
* 自定义图层；
* Heatmap；
* 动态数据；
* Popup；
* Camera；
* WebGL。

这样结构变成：

```text
HTML
 │
 ├── ECharts
 │     ↓
 │   折线图
 │   柱状图
 │   TOP10
 │
 └── MapLibre GL
       ↓
     3D青岛地图
     热力
     街道
     飞线
     AI事件
```

**ECharts继续负责图表，MapLibre专门负责地图。**

不要为了3D把现有所有ECharts推翻。

---

# 十四、如果追求更炫，可以考虑 deck.gl

后期：

> MapLibre + deck.gl

特别适合做：

* ArcLayer；
* HexagonLayer；
* HeatmapLayer；
* ScatterplotLayer；
* ColumnLayer。

例如人口可以直接做：

### 3D Hexagon

```text
      █
    █ █
  █ █ █
█ █ █ █ █
```

人口越多，六边形柱越高。

非常像数字孪生平台。

但是我建议：

> **第一版MapLibre就够了。**

不要继续扩大技术范围。

# 十五、页面视觉风格也要一起改

如果地图3D了，其他页面还是普通白底Bootstrap，会很违和。

建议：

### 背景

```text
#050B18
```

类似深蓝黑。

### Panel

半透明：

```text
rgba(10, 25, 50, 0.75)
```

加：

> backdrop-filter: blur()

形成玻璃面板。

### 边框

细蓝色发光线。

### 数字

大号数字：

```text
328,521
```

下面小字：

> 本年度患者

---

# 十六、动画不要太多

这是我特别提醒你的。

不要：

> 所有数字跳动
> 所有框发光
> 所有地图旋转
> 所有飞线不停飞
> 所有区域不停呼吸

那会很像十年前的大屏。

建议只有三种动画：

**① 地图Camera FlyTo**

用于AI事件定位。

**② AI重点区域呼吸光**

只突出异常区域。

**③ 医疗流向粒子**

速度很慢。

其他东西保持静态。

这样反而高级。

# 十七、最终比赛展示可以形成一个非常漂亮的过程

开场：

> **2026青岛医疗服务辐射全景**

3D青岛地图慢慢进入。

医院中心点亮起。

出现患者流向。

然后讲：

> “传统系统告诉我们一年有多少患者，但无法告诉我们医院的医疗服务真正覆盖了哪里。”

点击：

> **HRI**

整个青岛地图重新着色。

然后：

> “我们结合人口数据建立HRI医疗辐射指数。”

接着点击：

### AI智能巡检

右侧出现：

> **本期发现6项重要变化**

点击其中一项。

镜头：

> 青岛全景 → 城阳 → 某街道。

街道开始发光。

出现：

> 人口 +16.8%
> 患者 +4.2%
> HRI 0.43

AI：

> **“该区域人口持续增长，但医院服务覆盖增长明显滞后……”**

最后点击：

> ▶ 2020—2026

地图播放医疗辐射变化。

这个Demo故事会比现在单纯的平面热力图提升非常明显。

---

## 最终设计原则可以浓缩成一句话

> **地图负责“震撼”，数据负责“可信”，AI负责“洞察”。**

所以我不建议把整个系统全部3D化。**只把中间的青岛地图做成真正的3D空间地图**，左右统计和AI洞察继续2D；然后重点增加 **3D行政区、HRI发光、患者热力、医院辐射飞线、AI异常区域呼吸光、Camera FlyTo、2020—2026时空动画**。

这样既炫，又不会失去医院数智项目应有的专业感。
